## 開発作業の再開

ユーザーが「続けて」「再開」「続行」や continue / resume で現在の未完了の開発作業を続けるよう求めたら、`workstate-compass` Skill を適用する。文章の続き、引用中の語句、明示された新規タスクは対象外。

Skill 一覧の実パスを使って `SKILL.md` を読む。一覧にない場合は、導入時に確認した `~/.agents/skills/workstate-compass/SKILL.md` を確認する（Windows はユーザープロファイル配下）。リポジトリ単位で導入した場合は、この例のパスを導入先 `.agents/skills/workstate-compass/SKILL.md` の実パスに置き換える。

通常は直前の確定した状態から軽量に続行する。中断・成否不明・状態不整合があれば実ファイル、対象の Git 差分、検証結果、既存ジョブを必要な範囲だけ照合する。文脈不足なら同じタスクの進捗・チェックポイントから復元する。対象を特定できない場合だけ短く確認し、別チャットの作業を勝手に選ばない。

Skill を読めない場合はその旨を伝え、既知の文脈で安全に続けられる範囲を進める。未知の副作用を伴う処理は再実行せず、既存作業を巻き戻さない。Skill の自動インストールや既存設定の変更はしない。
